🐧 Linux / Systemd Cheatsheet

Essential commands

CommandWhat it does
systemctl start fooStart service foo
systemctl stop fooStop service foo
systemctl enable fooAuto-start on boot
systemctl status fooShow status + recent logs
journalctl -u foo -fFollow logs for service

Sample unit file

[Unit]
Description=WARPture tunnel agent
After=network.target

[Service]
Type=simple
ExecStart=/usr/local/bin/warpture-agent
Restart=on-failure
RestartSec=3

[Install]
WantedBy=multi-user.target

Drop this file at /etc/systemd/system/warpture.service, then run systemctl daemon-reload && systemctl enable --now warpture.
