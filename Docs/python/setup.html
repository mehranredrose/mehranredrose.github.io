🐍 Python / Environment Setup

Setting up a clean, reproducible Python environment is the first step in any project.

Creating a virtualenv

python3 -m venv .venv
source .venv/bin/activate      # macOS / Linux
.\.venv\Scripts\Activate.ps1   # Windows PowerShell

Using pyenv for version management

brew install pyenv            # macOS
pyenv install 3.12.0
pyenv local 3.12.0

requirements.txt vs pyproject.toml

For scripts and small projects, requirements.txt is fine. For distributable packages, prefer pyproject.toml with hatch or poetry.

[project]
name = "mypackage"
version = "0.1.0"
requires-python = ">=3.11"
dependencies = ["fastapi", "uvicorn"]
