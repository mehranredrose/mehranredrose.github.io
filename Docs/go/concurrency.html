🦫 Go / Goroutines & Channels

Go's concurrency model is built around goroutines (lightweight threads) and channels (typed message pipes).

Spawning a goroutine

go func() {
    fmt.Println("running in a goroutine")
}()

Communicating via channels

ch := make(chan int, 1)  // buffered channel
go func() { ch <- 42 }()
val := <-ch
fmt.Println(val) // 42

Select statement

select {
case msg := <-ch1:
    fmt.Println("ch1:", msg)
case msg := <-ch2:
    fmt.Println("ch2:", msg)
case <-time.After(1 * time.Second):
    fmt.Println("timeout")
}
